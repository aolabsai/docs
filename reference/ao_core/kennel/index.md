Kennels are **collections of Agents created by uploading an Arch**, making it possible to deploy unique Agents using that configuration for each end-user or application instance. Learn more and find existing Archs to work from at [our open ao\_loop1 repo](https://github.com/aolabsai/ao_loop1) .
