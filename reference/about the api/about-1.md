We are an applied AI research lab building the real-time reinforcement learning layer.

Our agents-as-a-service API has 2 main components:
- **Arch**[doc:kennelcreate], where you configure agents' neural architectures depending how many input and output neurons to encode for your data model (our neurons are binary)
- **Agent**[doc:agentinvoke], where you run agents from a set configuration; agents are light-weight and learn fast, no gap between training and inference

Though our core code is not public, we've made it accessible through a REST API as defined in this reference, and we have an open source pip-installable python wrapper library, [ao_pyth](https://pypi.org/project/ao-pyth/).

We'll help you build applications using our API and Agents; [connect directly our team](https://calendly.com/aee/meeting) .

[You'll need an API key, which you can get from us on discord](https://discord.gg/nHuJc4Y4n7).
